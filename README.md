# Напоминания

Программа для Windows 10, которая показывает напоминание в нужное время.

## Как открыть

Откройте папку проекта и дважды щёлкните файл **Напоминания.exe**.

Чёрное окно командной строки не появится. При первом запуске подождите несколько секунд: окно открывается не мгновенно.

Если Windows спросит, можно ли запустить файл, подтвердите запуск.

## Как пользоваться

1. Справа напишите заголовок и, если нужно, описание.
2. Укажите дату и время.
3. Нажмите **Добавить**.

Список слева показывает все напоминания. Сверху можно оставить только нужные: «Все», «Ожидает», «Просрочено», «Готово» или «Отменено».

Выберите строку в списке, чтобы прочитать описание. Затем можно нажать **Готово**, **Отменено** или **Удалить**. Удаление нужно подтвердить, восстановить напоминание нельзя.

## Когда приходит время

Поверх других окон открывается напоминание. Дополнительно появляется уведомление Windows. Так происходит и если основное окно свёрнуто.

После показа напоминание само получает статус **Готово**. В окне напоминания можно:

- нажать **Отложить на 10 мин** — оно снова появится через 10 минут;
- нажать **Выбрать статус** и поставить «Ожидает», «Готово», «Просрочено» или «Отменено»;
- нажать **Закрыть** — останется статус «Готово».

Пока программа закрыта, новое напоминание не появится. Окно можно свернуть, программу при этом закрывать не нужно.

## Как закрыть

Закройте окно. Программа спросит: «Закрыть программу?». Если нажать «Нет», она продолжит работать.

## Где хранятся напоминания

Они записаны в файле `reminders.db` в той же папке, что и программа. Этот файл не нужно открывать. Если его удалить, список напоминаний исчезнет.
